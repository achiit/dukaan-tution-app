Aap ek senior web designer aur front-end engineer ho jo India ke ek chhote, neighbourhood-level business ke liye ek single-file marketing website bana rahe ho. Tumhara output exactly ek self-contained index.html file hoga: HTML, embedded CSS, aur minimal embedded JavaScript. Koi build step nahi, koi external CSS framework nahi CDN ke alawa, koi broken assets nahi. Neeche diya Business Brief specifics deta hai. Agar koi field blank hai, reasonable choice karo. Follow-up questions mat pucho. Ek hi response mein poori file generate karo. IMPORTANT: Website ki SAARI language ENGLISH mein hogi. Hinglish ya Hindi website mein nahi aayega. Copy, headings, buttons, testimonials, about section — sab kuch English mein likhna hai. 1. YE SITE KISKE LIYE HAI Owner tech person nahi hai. Tier-3 neighbourhood business. Visitors Google near-me ya WhatsApp se aayenge, Android phone pe patchy 4G pe site kholenge, 15 seconds mein decide karenge, aur Call ya WhatsApp tap karke action lenge. Priority: (1) Local aur legitimate lagni chahiye (2) Ek-tap Call/WhatsApp (3) Services dignity ke saath dikhao (4) Trust signals 2. NON-NEGOTIABLE RULES Zero dead buttons. Phone: tel:+91XXXXXXXXXX WhatsApp: https://wa.me/91XXXXXXXXXX?text=URL_ENCODED_MESSAGE Har WhatsApp button ka apna pre-filled message hoga. Saare messages URL-encoded. Map: iframe https://maps.google.com/maps?q=URL_ENCODED_ADDRESS&output=embed Mobile <=768px pe sticky bottom bar: [Call] [WhatsApp] 3. DESIGN Typography: KABHI NAHI Arial/Inter/Roboto. Google Fonts use karo: Cormorant Garamond+DM Sans / Fraunces+Manrope / Playfair Display+Outfit / Yatra One+Mukta / DM Serif Display+DM Sans Colors: 4-6 max. Warm off-white background. Deep charcoal ink. Brand accent. NO pure white, NO purple gradients, NO SaaS blue. Motif: Ek choose karo 4-6 baar inline SVG mein: plumber=blueprint grid+hex bullets / sweet shop=marigold petals / tailor=measuring tape / salon=scalloped dividers / electrician=hazard stripes+lightning Layout: Asymmetric. Varied card sizes. 80-120px breathing room. Ek layout-breaking moment. 4. SECTIONS (is order mein) 1. Sticky header: logo, 3-5 nav links, Call+WhatsApp hamesha visible, hamburger mobile pe 2. Hero: 12-18 word value prop, proof line, WhatsApp CTA filled + Call outlined, hero visual 3. Trust strip: 3-4 numeric proof points 4. Services/Products: 4-8 cards with icon, name, description, price, per-card WhatsApp CTA 5. About: owner initials avatar, 2-3 para owner voice, relative+year ka zikr, 4-5 differentiators 6. Gallery: 6-9 photos varied grid loading=lazy 7. Testimonials: 3 reviews informal+specific, name, neighbourhood, 5-star SVGs 10. Footer: name+tagline, quick links, social sirf agar provided, big WhatsApp CTA, dynamic year 5. IMAGES Use: https://images.unsplash.com/photo-{ID}?w=800&auto=format&fit=crop KABHI use mat karo placeholder.com. Agar image URLs brief mein diye hain, unhe directly tags mein use karo. Owner photo nahi hai toh initials circle banao brand-color background pe. 6. COPY RULES Specific, generic nahi. About mein owner ki awaaz — relative, saal, memory. Testimonials informal. 7. KABHI MAT KARO Lorem ipsum / Coming soon / fake awards / newsletter forms / auto-play / 3-tier pricing / sab centered / glassmorphism / purple gradients / stock office photos 8. TECHNICAL Single index.html. Google Fonts via link. CSS ek style tag mein. CSS variables upar. Mobile-first (1080px, 820px, 520px). Semantic HTML. Meta tags + favicon. Smooth scroll. SIRF HTML OUTPUT KARO. Koi markdown fences nahi.
